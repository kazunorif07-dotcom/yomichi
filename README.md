# ヨミチ — 知の地図をつくる読書記録

スマホのブラウザで使える読書記録アプリです。インストール不要で、データは各自の端末（ブラウザ）の中に保存されます。

## できること
- 本の登録（分野18種・幹/枝/葉・状態〔読書中・積読・欲しい・読了・中断〕・言語・値段）
- 積読タワー／読了タワー（厚みから高さを推定し、身近な物と高さくらべ。総額・重さ・読み切るまでの時間）、本の検索と表紙の自動表示、表紙の写真登録
- 読書タイマー（一時停止・ミニプレーヤー）と手入力の記録、読む速さ（ページ/時）
- 進捗バーと読了予測日、連続読書日数、1日の目標リング、年間の読書チャレンジ
- 「知の版図」：18分野を国に見立てた六角形の世界地図。読了するたびに首都から領土が広がり、幹の本を読むと城が建つ
- 週・月ごとのグラフ、分野別の統計
- 本ごとのメモ（引用・自分の考え、ページ番号つき）、読了時の一言感想と本同士のつながり
- ホームに毎日1つ過去のメモを出す「今日のふりかえり」
- Markdown書き出し（AIに次に読む本を相談する質問文つき）
- データのコピー／貼り付けによる引っ越し・バックアップ

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目（色・文字・レイアウト） |
| `app.js` | 動き（保存・計算・描画・タイマー） |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |

本の検索には Google Books API・国立国会図書館サーチ・Open Library を使っています（Google Books が回数制限のときは、残りの2つで自動的に検索します）。分野は国立国会図書館の分類番号（NDC）から自動で判定します。
